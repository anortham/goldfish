Never touch

  • Tool and storage contracts — names, schemas, markdown, UTC, atomic writes, and locks remain unchanged.
  • Modern MRTR roots — explicitly outside this migration.
  • Real user state — spawned tests use temporary cwd, HOME, and GOLDFISH_HOME.

Held constant

  • Legacy clients — default serve posture and full roots regression suite.
  • Launch command — hosts still run the same Bun server path.
  • Workspace safety — explicit, environment, recovery, then refusal.

Verification gates

  • Worker — exact red/green tests, typecheck, and build where required.
  • Modern protocol — negotiated era, tool list/calls, isolation, and safe refusal.
  • Branch — full suite, tag guard, SDK-reference audit, and clean worktree inventory.
  • Security — none declared; official packages and absence of credentials still reviewed.
