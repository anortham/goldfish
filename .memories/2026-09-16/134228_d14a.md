## Documented the Codex plugin update path

**WHAT:** README Codex section gained an "Updating" block: `codex plugin marketplace upgrade`, then `codex plugin remove goldfish@goldfish`, then `codex plugin add goldfish@goldfish`.

**WHY:** `codex plugin remove` deletes the installed copy but keeps the marketplace snapshot. A plain remove-and-add reinstalls the same old version. Found while debugging the code-kb plugin on another machine.

**HOW:** Doc-only change. The goldfish Codex manifest already names its hooks file explicitly and has no root `plugin.json` with an `agent-plugins.org` `$schema`, which is the line that makes Codex skip `.codex-plugin` hooks.

**IMPACT:** Users can pick up new goldfish versions without a stale snapshot.
