## Fail-closed workspace design completed and adversarially reviewed

### WHAT

Updated the active brief and wrote `docs/plans/2026-08-30-fail-closed-workspace-identity-design.md`. The design makes workspace identity explicit for user-level MCP registrations and removes automatic cwd/registry recovery as authority.

### WHY

A live Codex call bound to the plugin cache. MCP 2026-07-28 is stateless and deprecates Roots, so server-local activation and ambient cwd cannot be a durable cross-client contract.

### HOW

The accepted sources are an explicit host-native absolute tool argument, fixed `GOLDFISH_WORKSPACE`, supported legacy Roots, and recall-only `all`. All sources receive unsafe-directory validation. Missing identity, relative/current paths, direct handler calls, and nested project paths fail closed with actionable suggestions.

A one-call Claude doubt pass found valid gaps around platform paths, unsafe explicit/env values, direct handler cwd fallback, nested memory stores, cache isolation, and stdio Roots coverage. The spec now includes them. It rejected the narrower cache blacklist because that preserves the structural cause.

### IMPACT

The caller-facing contract is ready for user review. No production code has changed. The next step is an isolated worktree, TDD implementation plan, and Luna-worker execution after approval.
