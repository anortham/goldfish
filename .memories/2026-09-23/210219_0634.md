## Release 8.0.5: worktree-accurate checkpoints

**WHAT:** Bumped all seven version surfaces to 8.0.5 and dated the CHANGELOG section 2026-09-23. The release ships commit a2fa868 (fast-forwarded from `fix/worktree-workspace-binding` to main).

**WHY:** Checkpoints saved in a git worktree recorded the main checkout's branch and commit, because git was read from the server's launch directory. The roots cache also went stale after Claude Code `EnterWorktree`.

**HOW:** Patch release. Git context now comes from the `workspace` path only. Roots are requested per call. The save reply shows the absolute path. All agent surfaces say to pass the worktree path in a worktree.

**IMPACT:** Users who update the plugin get correct branch metadata for worktree saves. Tag `v8.0.5`; branch and tag pushed separately so CI runs the version-tag job.
