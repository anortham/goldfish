## Added a GitHub Pages site for Goldfish

- **What:** New static site in `docs/site/` (`index.html`, `style.css`) and a deploy workflow `.github/workflows/pages.yml`. README now links to https://anortham.github.io/goldfish/.
- **Why:** The sister projects code-kb and julie-extractors have Pages sites; Goldfish had none. The user asked for a friendly page that explains benefits, best practices, and capabilities.
- **How:** Copied the code-kb pattern: plain HTML/CSS, no build step, deploy with `actions/upload-pages-artifact` from `docs/site` on pushes to main that touch the site. Own visual identity: pale water palette, goldfish orange accent, Bricolage Grotesque + JetBrains Mono, automatic dark mode. Hero is a three-tab session replay (work and save → context lost → recall) that uses the real checkpoint and recall output formats. Sections: why, three tools, benefits, best practices (weak vs strong checkpoint), six skills, per-client install tabs.
- **Decisions:** No version number on the site, so it cannot drift from the seven guarded version surfaces. No `.nojekyll` needed because the Actions deploy skips Jekyll.
- **Impact:** Pages is not yet on for the repo (API returned 404). After push, enable it with build type "workflow" or the first deploy fails.
