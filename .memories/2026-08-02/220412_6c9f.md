## Review follow-ups landed: test isolation, deps, CI

Fixed the three issues from today's check-in review, in three commits on main (54a3354, 4f3d334, feb85b8).

### Test isolation (`54a3354`)
- `tests/preload.ts` + `bunfig.toml` point `GOLDFISH_HOME` at a per-run temp dir before any test file loads; `tests/test-isolation.test.ts` guards it. The suite can no longer touch the real `~/.goldfish`.
- Two fallback-assertion tests (registry path, workspace home) now clear `GOLDFISH_HOME` explicitly.
- **Latent flake found and fixed:** two `limit:1` handler tests saved a checkpoint milliseconds after their describe-level `beforeEach` saves; same-millisecond timestamps tie in recall's sort and the filename hash decides the winner. Isolation made saves faster (tmpfs instead of real disk) and surfaced it at ~1 in 3 runs. Fixed by freezing those saves 1min ahead via `withFrozenTime`. **Deliberately no production sort change** — same-ms order is stable per dataset (spec-stable sort over filename-sorted input) and creation order within a millisecond is unknowable; no evidence of a real-world problem.
- Verified: 8/8 consecutive full-suite runs green, real registry byte-identical across runs.
- Also learned: pre-commit hook enforces `CLAUDE.md` == `AGENTS.md` (`cp CLAUDE.md AGENTS.md` after editing).

### Deps (`4f3d334`)
- MCP SDK 1.26.0 → 1.30.0, yaml 2.9.0, @types/bun 1.3.14 (now pinned `^` instead of floating `latest`). 621 tests + tsc clean on the new versions.
- **TS7 trial:** `bunx --package typescript@7 tsc --noEmit` fails only on tsconfig (`baseUrl` removed in TS7, non-relative `paths`). Migration is small; staying on 5.9 pinned until wanted.

### CI (`feb85b8`)
- `.github/workflows/ci.yml`: ubuntu, `bun install --frozen-lockfile` + `bun run typecheck` + `bun test` on push/PR; separate job runs `check:version-tag` on pushed `v*` tags (fetch-depth 0 so tags resolve).
