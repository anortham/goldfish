## Added /report-issue skill (shipping in 8.0.8)

**WHAT:** New `skills/report-issue/SKILL.md` (mirrored to `.agents/skills`), three evals in `evals/report-issue-*`, `.github/ISSUE_TEMPLATE/bug_report.md`, skill lists and counts updated in the README, the docs site, and CLAUDE.md.

**WHY:** The user asked for a skill like code-kb's `report-issue` so users can file Goldfish bugs easily.

**HOW:**
- No `bug-report` CLI like the one code-kb has. The skill collects facts with shell commands: the version from the last `server.start` log line (fallback: `package.json` two folders above the skill), `uname -sr`, `bun --version`, the client, and the install type.
- Only `[ERROR]`/`[WARN]` lines go in the report, not the whole log tail. `server.start` lines list the paths of other projects.
- Log lines are sorted by their ISO timestamps, because zsh glob order was not chronological here.
- Step 2 retries an unbound or non-absolute workspace error once before treating it as a bug.
- The user must approve the exact text before `gh issue create --repo anortham/goldfish`. Without `gh`, the skill gives the user the new-issue link.

**IMPACT:** 7 skills now. The skill lists in `tests/agent-assets.test.ts` and `tests/server.test.ts` include report-issue. The evals are not run yet (they cost money and need `--allow-tools Bash Write`).
