## Skills keep bare goldfish tool names

Reverted the line added in 326957e that named the goldfish MCP server and gave a host-prefixed example (`mcp__plugin_goldfish_goldfish__recall`). Removed the matching test in `tests/agent-assets.test.ts`.

- **Why:** the user does not want the Anthropic guide's "fully qualified MCP tool names" rule. Each harness (Claude Code, Codex, Cursor) uses a different prefix, and the bare `recall(...)` / `checkpoint(...)` / `brief(...)` style has worked in practice.
- **Scope:** the rest of the best-practices alignment stays: the "what, then Use when" descriptions, the checkpoint fixes, and the handoff trim.
- **Evals unaffected:** `evals/` graders use `mcp__plugin_goldfish_goldfish__*` because that is the name the eval runner gives the tools. That is not how the skills refer to them.
