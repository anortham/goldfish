## Implemented MCP SDK v2 legacy baseline

### WHAT

Task 1 migrated the Goldfish server and legacy integration tests from the monolithic MCP SDK to `@modelcontextprotocol/server@^2.0.0` plus `@modelcontextprotocol/client@^2.0.0`. The server now uses v2 method-string handlers, v2 handler context access, and v2 roots request typing. All test clients use the split client package, explicit legacy negotiation, and linked in-memory transports. Added the dependency contract test.

### WHY

This establishes the stable v2 package and type baseline while preserving the current legacy protocol behavior and all request-time roots recovery behavior. Modern stdio serving remains intentionally deferred to Task 2.

### HOW

Followed red-green TDD: the new dependency contract failed before package changes, then passed after the split packages were installed and the monolith was removed. Miller context, symbol inspection, reference tracing, and post-edit impact confirmed the affected server/test surface. Preserved roots caching, timeout, retry, notification invalidation, recovery, refusal, and cleanup assertions; only SDK syntax and negotiation configuration changed in tests. The v2 stdio import preflight also passed.

### IMPACT

Typecheck, all 56 `tests/server.test.ts` cases, the SDK migration contract test, and the Bun build pass. The owned slice is ready to commit; Task 2 can now switch `startServer()` to modern-capable `serveStdio` and add wire-level compatibility coverage.
