## Wrote the MCP SDK v2 stateless migration design

- **WHAT:** Added the canonical design at `docs/plans/2026-08-08-mcp-sdk-v2-stateless-migration-design.md` and its sibling visual digest HTML.
- **WHY:** Goldfish uses monolithic MCP SDK 1.30.0; stable split v2 packages and the 2026-07-28 stateless protocol require explicit server, handler, and test migration work.
- **HOW:** The design keeps protocol adaptation in `src/server.ts`, switches stdio startup to `serveStdio(() => createServer())`, moves tests to the v2 client, and adds spawned modern-stdio coverage with isolated cwd and `GOLDFISH_HOME`. An external doubt pass materially revised the design: legacy roots stays intact, while modern MRTR roots is deferred in favor of the existing explicit/env/cwd recovery and safe-refusal chain.
- **IMPACT:** The migration now has a bounded compatibility design, implementation sequence, acceptance criteria, architecture review, and release-prep scope. Implementation should begin only after user approval and must follow TDD.
