## Designed the MCP TypeScript SDK v2 migration boundary

Mapped the official v1-to-v2 and `2026-07-28` guides onto Goldfish's current low-level stdio server.

- **WHAT:** Identified the exact dependency, handler, transport, roots, test, documentation, and release surfaces that must change.
- **WHY:** A mechanical import migration alone leaves Goldfish on the 2025 wire protocol, while switching to modern-only would break existing clients.
- **HOW:** Chose a dual-era `serveStdio(() => createServer())` entry. Legacy requests retain cached push-style roots lookup; modern requests use `inputRequired.listRoots()` and consume `inputResponse()` on retry. Core workspace resolution continues accepting roots as data and remains unaware of MCP eras.
- **IMPACT:** The migration can preserve current clients while adding stateless protocol support. Architecture risk is medium because the low-level handler context and roots control flow change, but the public tool surface and markdown storage remain unchanged.
