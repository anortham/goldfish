## Verified TypeScript SDK support for stateless MCP

Goldfish is current on the monolithic v1 SDK but does not yet support the stateless `2026-07-28` protocol revision.

- **WHAT:** Confirmed Goldfish declares and installs `@modelcontextprotocol/sdk@1.30.0`; upstream's stable stateless implementation is the split v2 package set at `2.0.0`.
- **WHY:** The new MCP revision removes the mandatory initialize handshake and protocol sessions, so compatibility depends on SDK wire-protocol support rather than Goldfish's application storage model.
- **HOW:** Compared the local dependency and stdio entry point with the official MCP release announcement, TypeScript SDK releases, v1-to-v2 migration guide, and `2026-07-28` adoption guide.
- **IMPACT:** Changing the v1 range cannot enable the new revision. Goldfish needs a v2 migration and must replace direct `server.connect(new StdioServerTransport())` with `serveStdio(() => buildServer())`. Existing request-time `roots/list` behavior also needs explicit compatibility coverage because modern MCP removes the server-initiated request channel.
