## TODO item 2: brief, recall, and handoff guidance aligned

**WHAT:** Edited `skills/recall`, `skills/handoff`, and `skills/brief`, then synced the `.agents/skills` mirror. Also changed the recall trigger line in `src/tools.ts`.
- Recall is now conditional. The skill description says "resuming prior work", not "starting a new session". The body says not to recall by reflex at every session start, or to re-read a checkpoint saved in the same session.
- After a recall, the agent recovers the goal and constraints from the brief and the next action from the `next` line. It keeps recalled decisions but checks drift-prone facts against the current code and git. For more detail it searches or passes `full: true`, and does not read all of `.memories/`.
- Handoff no longer tells the agent to use the checkpoint `summary` field, which recall never returns (it is removed at `src/recall.ts:467`). A new rule says to check a historical claim, or mark it with its checkpoint date.
- Briefs now also exclude git logs, command output, and test transcripts.

**WHY:** TODO item 2 required this. The audit showed that the `next` line changed the most decisions, and that recalls right after compaction or of the agent's own recent saves mostly repeated context it already had.
