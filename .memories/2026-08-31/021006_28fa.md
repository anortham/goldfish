## Fixed the v8.0.0 CI setup race

### WHAT

Made the modern MCP refusal test create its `home` parent directory before creating `home/.memories` and the sibling Goldfish home directory.

### WHY

The release CI test job failed nondeterministically with `EEXIST` because `mkdir(home)` raced a recursive `mkdir(home/.memories)` inside the same `Promise.all`. The failure was in test scaffolding, not production workspace-binding behavior.

### HOW

Pulled the exact GitHub Actions failure, reproduced it locally under repetition, inspected the implicated test with Miller, and changed only the ordering of the two dependent filesystem operations. No production code or contract changed.

### IMPACT

The protocol compatibility test no longer races on Ubuntu/Fedora filesystem scheduling. The release branch can be reverified, but the already-published `v8.0.0` tag still points to the pre-fix commit and must either be moved with explicit approval or superseded by a new patch release.
