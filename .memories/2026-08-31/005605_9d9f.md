## WHAT
Completed and lead-reviewed the user-facing contract for fail-closed workspace identity across tool schemas, server instructions, static SessionStart guidance, all six Goldfish skills, generated mirrors, README, portability/implementation/editor docs, type comments, and the Unreleased changelog.

## WHY
Runtime refusal alone would keep agents in a retry loop if concrete examples still omitted `workspace`. User-level Codex, Cursor, and other MCP registrations need every shown current-project call to demonstrate the per-call absolute project root, while project-level fixed environment binding and supported legacy Roots remain valid.

## HOW
Added one shared tool workspace description and concise server/hook guidance. Every current-project checkpoint, brief, and recall example now includes `/absolute/path/to/project`; explicit `workspace: "all"` remains cross-project-only. Guidance says host-native absolute paths, fixed absolute `GOLDFISH_WORKSPACE`, and supported legacy Roots. Canonical skills were regenerated into `.agents/skills`, AGENTS/CLAUDE, and the usage document. Tests scan current examples, enforce mirrored assets and type comments, and retain the 2,000/10,000 character caps. Focused result: 93 pass, 0 fail; instructions 1,982 chars; hook 4,491; tool descriptions 1,379/1,457/1,605.

## IMPACT
Agents now receive an enforceable and copyable workspace contract in every supported harness surface. User-level registrations no longer rely on cwd/current/recovery claims, project-level binding remains documented, and no dynamic hooks, activation state, version bump, push, or release was introduced.
