## WHAT

Released Goldfish 8.0.1 as a superseding patch instead of rewriting the published `v8.0.0` tag.

- Bumped all seven version surfaces to 8.0.1: `src/server.ts`, `package.json`, `.claude-plugin/plugin.json`, `.codex-plugin/plugin.json`, `.claude-plugin/marketplace.json`, `.cursor-plugin/plugin.json`, and the `README.md` banner.
- Added a `## [8.0.1]` CHANGELOG section recording the test fix and stating that `v8.0.0` is superseded.
- Fast-forwarded `main` from 7.9.0 (`24133f1`) to the fail-closed workspace identity work at `402ef1a` and pushed it. CI passed.

## WHY

The 8.0.0 release was tagged before its CI run finished. The run failed on a test-setup race, and the fix commit landed after the tag. A published tag pointing at a red commit is a trap for anyone installing by tag.

## HOW

Reverted three uncommitted manifest files in the main checkout that had local machine paths (`/home/murphy/.local/bin/bun`, an absolute `src/server.ts`) substituted for the portable `bun` command and `${PLUGIN_ROOT}` placeholder. Those would have broken the plugin for every other user had they shipped. The diff is preserved as a patch outside the repo.

Chose the patch release over a tag force-move because `v8.0.0` was already on the remote.

## IMPACT

8.0.1 is the first 8.x tag whose commit passed CI. The breaking workspace-binding change from 8.0.0 ships unchanged.

Two follow-ups remain, neither blocking:

- The storage layer re-validates already-bound paths. `getBrief`, `listBriefs`, `getActiveBrief`, `getCheckpointsForDay`, `getAllCheckpoints`, `getCheckpointsForDateRange`, and others each call `resolveWorkspace()` on a path the caller resolved. A 30-day recall repeats the stat/realpath/parent-walk about 30 times. Idempotent, so it is waste rather than a defect.
- CI does not run on feature branches; the workflow triggers only on `main` and `v*` tags. The race fix reached CI only after the merge.
